# 抖音公开作品本地归档

这是一个供个人归档已获授权的**公开**作品的本地命令行工具。它只读取浏览器已呈现页面中可见的公开信息和公开媒体资源；不保存账号密码、不处理私密/付费内容，也不去水印或绕过访问限制。

## 安装

在本目录运行：

```powershell
npm install
npx playwright install chromium
```

## 使用

首次运行会打开独立浏览器窗口。请自行完成抖音登录或验证码；登录状态只保存在当前 Windows 用户的 `%LOCALAPPDATA%\DouyinPublicArchive\browser-profile` 中，不在项目目录内。

归档一个或多个作品：

```powershell
npm run archive -- "https://www.douyin.com/video/作品ID"
npm run archive -- "作品链接1" "作品链接2"
```

从博主主页收集公开作品并归档（支持分批：从第几个开始、本批抓几个）：

```powershell
npm run profile -- "https://www.douyin.com/user/用户ID" --start 1 --max 30
```

也可以直接双击 `启动网页工具.bat`，在打开的 `http://127.0.0.1:3211` 网页里粘贴主页链接、填写“从第几个作品开始”和“本批下载数量”。

输出为扁平结构：`archive-data/博主名/发布日期_标题_作品ID.mp4`（图文作品为 `..._01.jpg、_02.jpg`），不再创建作品子文件夹；若无法识别作者或作品发布时间，工具会中止该作品，不会创建“未知博主”或用采集日期代替。

- 视频/图片直接平铺在博主文件夹内，按日期排序即按发布时间排列
- `作品清单.csv`：该博主目录下的汇总清单（含标题、作品链接、文件名），可用 Excel 打开
- `_记录/`：程序运行所需的结构化记录，用于断点续抓和去重，平时不用管、不要删

## 发给别人前：安全打包

压缩包中只保留：

```text
package.json
package-lock.json
README.md
.gitignore
src/
```

不要打包以下内容：

```text
archive-data/           # 已下载作品及采集记录
node_modules/           # 体积大，接收者可自行安装
*.log                   # 可能包含作品链接或故障信息
```

接收者解压后，在项目目录运行：

```powershell
npm install
npx playwright install chromium
npm run profile -- "博主主页链接" --max 20
```

首次运行会打开独立浏览器窗口；接收者需使用自己的账号手动登录。Cookie 保存在其自己的 Windows AppData，不会随项目压缩包发送。一个批量任务只使用同一个浏览器窗口，顺序处理作品。

## 说明

- 页面结构会变；工具若找不到作品或媒体，会留下 `metadata.json`，可据此定位问题。
- `--start` 默认 1（从第 1 个作品开始），`--max` 默认 20（本批数量，网页端上限 500）。建议小批量、低频执行。
- 主页加载出的推荐流会混入作品链接，但每条作品都必须与目标博主名称严格一致；非目标作品只会跳过，不会提前终止整批，也不会归档不明作者。
- 中断任务后，再次输入同一主页链接会从上次处理位置继续；断点仅保存在当前用户的 AppData，不随压缩包发送。
- 默认节奏已优化为单作品约 2-4 秒、作品间隔约 1.5-3 秒；同一视频的多个候选地址只会下载到首个成功文件。单条识别失败会自动重试一次，仍失败则跳过该条并继续后续作品。
- 注意：博主若在两次分批任务之间发布了新作品，主页上的“第 N 个”位置会前移，但已下载的作品不会重复。出现验证码或访问异常时停止操作并由你在窗口中处理。
- 媒体资源带有临时授权时，工具只会在其可访问期间保存，不会尝试生成、破解或延长访问令牌。
