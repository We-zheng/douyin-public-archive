# 抖音公开作品本地归档

这是一个供个人归档已获授权的**公开**作品的本地工具。它只读取浏览器已呈现的公开信息和公开媒体资源；不保存账号密码，不处理私密/付费内容，也不去水印或绕过访问限制。

## 最简单的使用方式（便携版）

下载 `抖音公开作品归档-便携版.zip`，解压后双击 `启动网页工具.bat`。便携版已包含 Node.js、依赖和 Chromium，不需要另外安装软件。

网页地址是 `http://127.0.0.1:3211`。粘贴博主主页或抖音分享短链，填写起始作品和数量后点击“开始归档”。需要中断时请点网页里的“停止任务”，等待状态变成“任务已停止”；再次提交同一个链接会接着上次的断点执行。

登录 Cookie 和断点只保存在当前 Windows 用户的 `%LOCALAPPDATA%\DouyinPublicArchive`，不在项目或压缩包中。作品保存在工具目录的 `archive-data`。

## 源码运行方式

在本目录运行：

```powershell
npm install
npx playwright install chromium
```

随后可双击 `启动网页工具.bat`，或使用命令行：

```powershell
npm run archive -- "https://www.douyin.com/video/作品ID"
npm run profile -- "https://www.douyin.com/user/用户ID" --start 1 --max 30
```

`--start` 表示目标博主自己的第 N 个作品，不是页面里混入的推荐链接序号；`--max` 表示本次需要确认并处理的目标作品数，网页端上限 500。

## 输出结构

输出为扁平结构：`archive-data/博主名/发布日期_标题_作品ID.mp4`；图文作品为 `..._01.jpg、_02.jpg`。发布日期取自作品公开发布时间，不使用下载日期。无法识别作者或发布时间时不会归到“未知博主”。

- `作品清单.csv`：该博主的汇总清单，可用 Excel 打开
- `_记录/`：完成状态和媒体记录，用于去重；平时不要删除
- 媒体只在全部图片成功，或至少一个有效视频地址下载成功后，才会标记为完成

## 断点、混入内容和停止

- 主页作品会同时从虚拟列表 DOM 和作品接口响应累计，避免滚动后旧节点被移除而只抓到前几十条；每条候选作品仍会核对作者，推荐流或其他博主内容不会写进目标目录。
- 断点记录包含候选位置、已确认目标作品数、起始位置和本批目标数；中断后不会从零重新计数。
- 旧版断点因缺少可靠计数会自动重新扫描，但已完成作品会去重，不会重复下载。
- 达到本批目标后会清除断点；候选池扫描完仍不足时，下次会重新加载主页。
- 不要直接关闭浏览器来停止任务，请点击网页“停止任务”。关闭网页工具进程时，后台归档子进程也会一并终止。

## 发布与隐私

源码仓库不会提交 `archive-data/`、`node_modules/`、日志、便携版目录或 ZIP。发布给普通用户时，上传重新生成的 `抖音公开作品归档-便携版.zip` 到 GitHub Releases；不要把本机 `%LOCALAPPDATA%\DouyinPublicArchive` 加进压缩包。

建议小批量、低频执行。出现验证码、访问异常或账号风险提示时应停止操作并在浏览器中人工处理；工具不能保证平台不会因自动访问触发限制。
